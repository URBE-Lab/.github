## Where things live

| Tool | Used for |

## Sensitive data

Patient-level and restricted-use data (EHR, PHI, files covered by data use agreements) stay in approved secure computing environments. They are never committed to GitHub, posted in Slack, attached to Trello cards, or sent by email. Every repository ignores data files by default, and that includes small test extracts.

## GitHub

- One private repository per project, with one repository per independent student project and one shared repository for group projects.
- Group projects use branches and pull requests, with at least one reviewer before merging.
- Every repository has a README describing the question, the folder structure, and how to reproduce the analysis.

## Tasks and planning

- **One board per project**, plus a lab overview board for milestones only: submissions, IRB renewals, abstract deadlines, and committee meetings.
- **Columns:** Backlog, This week, In progress, Review, Done.
- **Every card has one owner and a due date.** A card with no owner or date returns to Backlog.
- **Size:** a task should take about 1 to 5 working days and never more than a week. Larger work is split into smaller cards.
- **Limit:** at most three cards in progress per person.
- **Horizon:** detailed tasks for the next two to three weeks, and milestones further out. A milestone is broken into tasks about two weeks before work on it starts.
- The backlog is pruned monthly, and anything untouched for 4 to 6 weeks is archived.

## Weekly rhythm

A short weekly check-in with each student covers updating their cards, what is blocked, and what is next. Done cards are archived at that meeting.
